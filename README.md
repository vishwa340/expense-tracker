# Expense Tracker

A simple and user-friendly Expense Tracker web application built using HTML, CSS and JavaScript.

## Features

- Add income and expenses
- Track total balance
- View transaction history
- Delete transactions
- Simple and responsive design
- Easy to use interface

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Use

1. Enter the transaction name.
2. Enter the amount.
3. Select Income or Expense.
4. Click the Add Transaction button.
5. Your transaction will appear in the history.

## Project Purpose

This project was created to practice JavaScript DOM manipulation, events, arrays and basic web development concepts.
